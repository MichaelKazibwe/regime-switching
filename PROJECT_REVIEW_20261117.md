## Reproduction details

### B1 — FX observation session is not enforced

Synthetic London price: session `2026-11-16`, available `2026-11-16T16:35:00Z`, close 3,000 GBX. USD valuation: `2026-11-16T21:00:00Z`. GBP/USD rate: 1.25, available `2026-11-16T18:00:00Z`.

Both FX observation sessions below were accepted by `base_currency_panel`, returning **USD 37.50**:

- `2026-11-17` — observation date after the valuation date.
- `2020-01-02` — an obsolete observation with a newly stamped availability time.

This shows a timestamp-contract hole. It does not establish that the current USD-listed portfolios contain such FX marks; the native foreign listings are not research-enabled by default.

### B2 — unavailable reference becomes cash

`cycle_benchmark.account` received four synthetic MSFT daily returns and reference weights `{'SPY': .6, 'IEF': .4}`. It returned zero return, zero volatility, zero drawdown and zero turnover rather than rejecting or marking the reference unavailable.

The current default universe includes SPY and IEF, so this reproduction is a defect in alternate-universe/reference handling, not evidence that today's displayed 60/40 metrics are zero or incorrect.

## Recommended execution order

1. Fix B1 and B2 with adversarial regression tests; preserve all original artifacts and label any recomputation as a new version.
2. Fix A4–A7: accurate job states, live telemetry, capability readiness and complete image packaging. These make failures visible before adding further features.
3. Implement A1–A3 before exposing the pilot remotely: portable publication, exact-image/security/TLS qualification and a current off-host restore drill.
4. Strengthen C2–C4 and C6–C7: macro-mask validation/protocol lifecycle, data-gap diagnosis, look-through exposure and realistic net-risk analysis.
5. Freeze and collect the prospective comparisons in C1/C5/C8. Continue genuine monitoring; do not backfill outcomes or claim improved returns from software tests.
6. Implement D1–D9 through small reviewable changes, with acceptance criteria tied to the current architecture. Add D10 capabilities only after their individual admission evidence exists.

The two reproduced correctness defects should be fixed before expanding native-FX use or relying on arbitrary-universe reference comparisons. The current research-only gates, original ledgers and fail-closed behavior should remain in place throughout these improvements.
